# ROAD RUSH – Cyber Security Racing Game

## 503IT Communication and Collaboration

Road Rush is an interactive cyber-security racing game where the player drives through digital roads, avoids enemy vehicles, collects cyber powerups, answers cyber-security questions, earns coins, and unlocks levels.

## Main Features

- Register, login and logout system
- Dashboard page after login
- Profile page hidden until login
- Garage with selectable car models
- Male/Female driver selection
- 3D-style racing graphics using HTML/CSS
- Keyboard, mouse and touch movement
- Locked level progression
- Distance-based level completion
- Cyber-security quiz questions
- Lives, score and coin system
- Powerups: shield, nitro and data collection
- Sound effects using browser audio
- Game over, restart and mission complete screens

## Gameplay

The player controls a racing car and must survive until the distance target is completed. The player collects coins, shields and nitro boosts while avoiding enemy cars, malware traps and road hazards.

If the player crashes, a cyber-security question appears. A correct answer gives the player another chance, while wrong answers reduce lives. At the end of each level, a final boss cyber quiz must be answered correctly to unlock the next level.

## Levels

### Level 1: Safe Password City
- Distance target: 1200m
- Slower traffic
- Basic cyber-security questions
- Focus: password safety and safe links

### Level 2: Phishing Highway
- Distance target: 1600m
- Faster traffic
- More cyber traps
- Focus: phishing, scams and suspicious emails

### Level 3: Dark Web Rush
- Distance target: 2200m
- Hardest speed
- Malware and hazard attacks
- Focus: malware, ransomware, privacy and account recovery

## Educational Purpose

Road Rush teaches players about:

- Password security
- Phishing attacks
- Online privacy
- Safe browsing
- Scam awareness
- Malware and ransomware
- Two-factor authentication
- Digital responsibility

The game uses racing challenges and cyber questions to make digital safety learning more engaging and memorable.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Web Audio API

## How to Run

1. Download and extract the ZIP folder.
2. Open the project folder.
3. Double-click `index.html`.
4. Register an account.
5. Select a car and driver from the garage.
6. Start Level 1 from the dashboard.
