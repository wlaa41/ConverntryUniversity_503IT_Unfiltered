# Digital Mirror

## Project Overview
**Digital Mirror** is an educational game project designed to teach and engage users through interactive gameplay and digital storytelling. The game focuses on learning, communication, and collaboration skills in an engaging digital environment.

This project is being developed as part of the **503IT Communication and Collaboration** course.

---

## Project Goals
- Create an interactive educational game
- Improve teamwork and collaboration skills
- Apply Agile project management techniques
- Develop communication and problem-solving abilities
- Deliver a functional and user-friendly gaming experience
