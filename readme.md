# Description
**Digital Mirror** is an interactive story-based game developed to spread awareness about digital life and cybersecurity through realistic situations and decision-making.

The player begins as an aspiring digital content creator trying to become famous in the online world. Throughout the journey, players face challenges such as phishing scams, cyberbullying, fake sponsorships, privacy threats, misinformation, and online pressure.

Every decision affects the player's:

- Followers
- Reputation
- Security
- Mental Health

# Features

The game combines entertainment, storytelling, and educational awareness in a modern digital-life simulation experience.

- Login / Register System
- Character Selection (Boy/Girl)
- Interactive Story Gameplay
- Multiple Choices & Consequences
- Cybersecurity Awareness
- Animated User Interface
- Sound Effects
- Progression Roadmap
- Multiple Endings
- Profile & Settings Page
- Realistic Social Media Inspired Design
- Reputation & Security System

---

# Gameplay Concept

The player progresses through different stages of becoming a famous creator.

## Each Stage Contains:
- Conversations
- Challenges
- Risky Situations
- Cybersecurity-Related Decisions

## Correct Decisions Improve:
- Trust
- Security
- Healthy Online Growth

## Wrong Decisions Can Lead To:
- Hacked Accounts
- Loss of Followers
- Cyberbullying
- Reputation Damage
- Stress and Burnout

# Educational Purpose

Designed to:

- Promote Cybersecurity Awareness
- Teach Ethical Online Behaviour
- Demonstrate the Dangers of the Digital World
- Encourage Safe Social Media Practices
- Educate Users Through Interactive Storytelling

Instead of directly teaching cybersecurity, the game naturally integrates cyber-awareness into real-life digital experiences.
