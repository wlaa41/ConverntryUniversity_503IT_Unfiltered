## 503IT Communication and Collaboration

# Description

**Road Rush** is an interactive cyber-security racing game developed as part of the **503IT Communication and Collaboration** module.

The game combines high-speed racing gameplay with educational cyber-security awareness. Players control a white racing car while avoiding incoming enemy vehicles on the road. If the player crashes into an enemy car, a cyber-security question appears. Correct answers allow the player to continue playing, while incorrect answers result in losing the game.

The game is designed to make cyber-security learning more engaging, interactive, and enjoyable through gameplay mechanics inspired by modern racing games.

# Gameplay Concept

The player controls a racing car and must avoid collisions with other vehicles on the road.

If the player's car is involved in a collision:

1. The player loses one life.
2. The game continues if the player has remaining lives.
3. The game ends when all lives are lost.

Cyber-security questions appear periodically during gameplay.

1. If the answer is correct:
   - The player gains an extra life.
2. If the answer is incorrect:
   - The player loses 100 coins.
3. The game then continues.
The game contains three levels:

## Easy Mode

* Slower traffic
* Basic cyber-security questions

## Medium Mode

* Faster enemy cars
* Intermediate cyber-security questions

## Hard Mode

* High-speed gameplay
* Advanced cyber-security awareness questions

Each level contains 5 educational questions.

# Educational Purpose

The aim of the game is to spread awareness about cyber-security and digital safety in a fun and engaging way.

The game teaches players about:

* Password Security
* Phishing Attacks
* Online Privacy
* Safe Browsing
* Cyberbullying
* Scam Awareness
* Digital Responsibility

Instead of traditional learning methods, the game integrates cyber-security education directly into gameplay.
